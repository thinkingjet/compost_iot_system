Pairing & security

How a device joins your account, the safeguards on pairing codes and device keys, and what to do if one is exposed.

A device joins an account in one of two ways. Pairing: the device redeems a 6-digit code from the dashboard and receives its own key. Registering with an API key: for a device that can't pair, you name it and choose its bin in the dashboard, which shows its key once for you to copy onto the device.

Pairing code
6 digits, single use
Code lifetime
10 minutes
Wrong-code limit
10 per 15 minutes, per IP

Pairing codes

When you add a device, the dashboard creates a 6-digit code. You enter it on the device's own page, and the device redeems it with the API. The code is the only thing that links a device to your account, so it is deliberately short-lived.

Single useMarked as used the moment a device redeems it.
ExpiresAfter 10 minutes. Ask the dashboard for a new one.
Account-boundIt can only add a device to the account that created it.
Guess-limitedAfter 10 wrong codes in 15 minutes from one IP address, the API answers 429. The proxy also limits pairing requests to 10 a minute per IP.
Carries nothing elseNo bin, name or location is attached to the code.

Device keys

Every device has its own API key, which it sends in the x-key header with every upload to POST /records. The key can do nothing else.

Random32 random bytes, sent as 64 hex characters.
Shown onceA paired device receives its key in the redeem response, and it is never shown to you. A registered device's key is shown to you once, to copy onto the device.
Stored as a hashThe API keeps only a SHA-256 hash, so the key can't be read back from the database.
Revoked on removalRemoving a device in the dashboard revokes its key at once. Later uploads get 401, and the device can be paired again.

Pairing step by step

  1. 1
    Dashboard

    Get a code. Choose Pair a device, then Get pairing code. The code works for 10 minutes. POST /pairing/codes

  2. 2
    Device page

    Enter the code. The device sends it with its hardware ID and receives its key. POST /pairing/redeem

  3. 3
    Dashboard

    Check the hardware ID. The dashboard shows which device redeemed the code. Make sure it matches the ID on the device's page. GET /pairing/codes/{code}

  4. 4
    Dashboard

    Confirm. Name the device and choose its bin. Until you do, its uploads are answered with 409. POST /devices/{id}/setup

If the hardware ID in step 3 isn't yours, don't confirm it. Remove the device and create a new code. An unconfirmed device can't add readings to your account.

If a code or key is exposed

What was exposedWhat to do
A pairing code nobody has usedNothing. Let it expire, or create a new one.
A pairing code someone else redeemedDon't confirm the unknown hardware ID. Remove it and create a new code.
A paired device's keyRemove the device in its settings, then pair it again. The old key stops working when you remove it.
A registered device's keyChoose New API key in the device's settings and copy the new key onto the device. The old one stops working at once.
Your passwordChange it on the account page. Sessions that are already signed in end within 8 hours.

Accounts and sessions

PasswordsHashed with Argon2id. A wrong email and a wrong password get the same 401 response.
Sign-in limit10 requests a minute per IP to /auth/, then 429.
SessionsAn 8-hour token, kept in a signed, HttpOnly cookie that page scripts can't read.
TransportHTTPS only, with HSTS on the website, the dashboard and the API.
OwnershipEvery bin, device, reading and alert query is filtered by owner. Anything you don't own returns 404.
Deleting an accountDeletes your bins, readings, alerts, pairing codes and research keys, and releases your devices with their keys revoked, so they can be paired again.

What the open data includes

The research API only ever returns figures summed up per country: never names, emails, bin names, locations finer than country, or device identifiers. It needs a research key, which only a researcher account can create. Keys are stored as SHA-256 hashes, and deleting one stops it working at once. The data dictionary lists every field.

The public figures on this website need no key and are coarser still: totals across every bin, the number of bins in each country, and daily averages across all bins.
