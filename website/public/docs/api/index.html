Docs/API reference/Research data

Daily figures

GEThttps://api.compostiq.win/research/daily

One row per country per UTC day: how many bins and readings it covers, and the average, minimum, maximum and standard deviation of each sensor.

Research keyUp to 366 daysJSON or CSV

Authentication

Send your research key in the x-research-key header. Create one on the API keys page of a researcher account; you can hold up to five. A key is shown once, and deleting it stops it working at once.

Query parameters

All optional.

startdate-timeEarliest reading to include, inclusive. Must include a timezone, for example 2026-09-01T00:00:00Z. Defaults to 30 days before end.
enddate-timeLatest reading to include, exclusive. Must include a timezone. Defaults to now.
country_codestringISO 3166-1 alpha-2 code, for example ID. Upper or lower case.
formatenumjson (the default) or csv.

The window from start to end can be up to 366 days long.

Response

start, enddate-timeThe window the figures cover.
country_codestring | nullThe country you asked for, or null for every country.
dataarrayOne row per country per day, ordered by country, then day. Each field is described in the data dictionary.

With format=csv the response is just the rows, with a header line.

Errors

Errors come back as JSON with a detail field.

StatusWhen
401No x-research-key header, or the key is wrong, deleted, or belongs to an account that isn't a researcher's.
422start or end has no timezone, start isn't before end, the window is longer than 366 days, or country_code or format isn't a value listed above.
 
curl -G https://api.compostiq.win/research/daily \
  -H "x-research-key: $COMPOSTIQ_KEY" \
  -d country_code=ID \
  -d start=2026-10-01T00:00:00Z \
  -d end=2026-10-03T00:00:00Z
import os
import requests

resp = requests.get(
    "https://api.compostiq.win/research/daily",
    headers={"x-research-key": os.environ["COMPOSTIQ_KEY"]},
    params={
        "country_code": "ID",
        "start": "2026-10-01T00:00:00Z",
        "end": "2026-10-03T00:00:00Z",
    },
    timeout=30,
)
resp.raise_for_status()
for row in resp.json()["data"]:
    print(row["day"], row["temperature_c"])

Other endpoints

The research endpoints take the same key. /research/overview and /research/alerts take the same parameters and return the same envelope.

GET /research/overviewOne row per country for the whole window: bin and reading counts, and each sensor's average, minimum, maximum and standard deviation.
GET /research/alertsOne row per country and alert type raised in the window: how many alerts, in how many bins, and the average hours until they resolved.
GET /research/countriesEvery country with readings: bins, readings, and the first and last reading. Covers all time and takes no parameters.
GET /public/statsTotals: bins, countries, active devices, readings in the last 24 hours. GET /public/bins-by-countryNumber of bins in each country. GET /public/trends30-day daily means of temperature and moisture across all bins. GET /openapi.jsonThe machine-readable spec, for code generators and Postman.
