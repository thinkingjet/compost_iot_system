Open data for research

Compost piles, country by country.

Readings from working compost bins, summed up per country for each day or for a whole period: temperature, moisture, oxygen, CO₂ and ammonia, with how often each alert happens. Free for research with a researcher account and an API key.

What's in a row

One row per country, per day.

Readings from every bin in a country are summed up for each UTC day (/research/daily) or for the whole period you ask for (/research/overview). JSON and CSV carry the same fields.

FieldType · unitWhat it means
country_codeISO 3166-1 alpha-2Where the bins are, at country level only. For example ID.
dayISO 8601 · UTCThe UTC day the row covers. Daily rows only.
bin_countintegerHow many bins sent readings.
reading_countintegerHow many readings the row sums up.
temperature_cnumber · °CAverage core temperature of the piles.
moisture_percentnumber · %Average moisture content.
o2_percentnumber · %Average oxygen in the piles, 0 to 21.
co2_percentnumber · %Average carbon dioxide in the piles.
nh3_rationumber · 0–1Average relative ammonia intensity. Not a ppm value.
…_min, …_max, …_sdnumberFor each sensor above: its lowest and highest reading, and the standard deviation. Every figure is rounded to 3 decimals.

/research/alerts has one row per country and alert type instead:

FieldType · unitWhat it means
country_codeISO 3166-1 alpha-2Where the bins are.
typeenumtoo_hot, too_dry, too_wet, low_oxygen or high_co2.
alert_countintegerHow many alerts of this type were raised in the window.
bin_countintegerHow many bins raised them.
avg_hours_to_resolvenumber · hoursHow long they took to clear, on average. Alerts still open are left out of it.
How we anonymise

Everything about the pile. Nothing about the person.

Removed
  • Names and email addresses
  • Bin names
  • Addresses and coordinates
  • Device MAC addresses and hardware IDs
  • Account, bin and device database IDs
Coarsened
  • Location becomes a country code
  • Time becomes UTC days, or the whole period you ask for
  • Every bin in a country becomes one row
Left out
  • Bins with no country set
  • Offline alerts, which are never stored
  • A deleted account's bins, at once: every request reads the live data
Know your sensors

Read this before you publish.

Averages hide spread

Every sensor comes with its minimum, maximum and standard deviation (_min, _max, _sd). Check them before comparing averages.

Ammonia is relative

nh3_ratio runs from 0 to 1. It shows when ammonia rises and falls, not how much is present.

A tropical baseline

The pilot site sits at 24–32 °C ambient, so piles start near 28 °C and cool back to it. Expect higher floors than temperate data.

Days are UTC

Daily rows follow UTC days. The pilot site is at UTC+8, so one local day spans two rows.

Phase definitions

The ranges behind each stage.

The ranges CompostIQ's simulated piles follow (simulator/composting_stages.py). Peak decomposition starts once the core has held 55 °C for 6 hours.

StageTemperatureMoistureOxygenCO₂Typical length
0 Early mesophilic28–45 °C60–65 %15.5–21 %0.5–5.5 %1–3 days
1 Active thermophilic45–60 °C55–60 %12–17.5 %3.5–9 %2–4 days
2 Peak decomposition55–65 °C50–58 %10–16.5 %4.5–11 %4–7 days
3 Cooling30–60 °C45–55 %11–20 %1–10 %5–10 days
