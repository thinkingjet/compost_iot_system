List readings

GET{{ public_api_url }}/research/readings

Anonymised readings, one row per bin per hour, oldest first. Filter by country, method, phase or time, and page through the results with a cursor.

No key needed60 requests / minuteUp to 5000 rows per page

Query parameters

All optional. Combine as many as you like.

countrystringISO 3166-1 alpha-2 code, for example ID.
methodenumtakakura, bokashi or aerated_static_pile.
stageinteger 0–4Only hours labelled with this phase. See the phase definitions.
bin_refstringOne bin's readings. References come from /research/bins.
fromdate-timeEarliest hour to include, UTC. Inclusive.
todate-timeLatest hour to include, UTC. Exclusive.
limitintegerRows per page. Default 500, maximum 5000.
cursorstringThe next_cursor from the previous page.

Response

itemsarrayReadings. Each field is described in the data dictionary.
next_cursorstring | nullPass this as cursor to get the next page. null on the last page.

Rate limits & errors

Every client IP can make 60 requests a minute. Errors share one shape: {"detail": "A sentence you can show to a person."}

StatusWhen
400A parameter isn't recognised, for example method=compost.
422A value is out of range, for example limit=9000.
429Over 60 requests in a minute. Wait for the number of seconds in Retry-After.
503Down for maintenance. Try again shortly, or use the bulk files.
 
curl -G {{ public_api_url }}/research/readings \
  -d method=takakura \
  -d from=2026-08-26T00:00:00Z \
  -d limit=2
import requests

resp = requests.get(
    "{{ public_api_url }}/research/readings",
    params={
        "method": "takakura",
        "from": "2026-08-26T00:00:00Z",
        "limit": 2,
    },
    timeout=30,
)
resp.raise_for_status()
for row in resp.json()["items"]:
    print(row["recorded_at"], row["temperature_c"])
