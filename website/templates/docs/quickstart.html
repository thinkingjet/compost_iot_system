Quickstart

Make your first request to the CompostIQ open API in about five minutes. You don't need an account or a key.

Base URL
{{ public_api_url }}
Format
JSON, times in UTC
Rate limit
60 requests a minute per IP
1

Check the API is up

Ask for the headline numbers. If this works, everything else will too.

Terminal
$ curl {{ public_api_url }}/public/stats
Response · 200
{
  "bins": {{ stats.bins }},
  "countries": {{ stats.countries }},
  "active_devices": {{ stats.active_devices }},
  "readings_24h": {{ stats.readings_24h }},
  "updated_at": "{{ stats.updated_at.strftime('%Y-%m-%dT%H:%M:%SZ') }}"
}
2

Fetch some readings

Readings come one row per bin per hour, oldest first. Filter them with query parameters; these three are the ones you'll use most.

Terminal
$ curl -G {{ public_api_url }}/research/readings \
    -d method=takakura \
    -d from=2026-08-18T00:00:00Z \
    -d limit=100
methodtakakura, bokashi or aerated_static_pile
fromEarliest hour to include, ISO 8601 in UTC
limitRows per page. Default 500, maximum 5000

Every filter is in the API reference.

3

Load them into pandas

The items array drops straight into a DataFrame.

Python
import pandas as pd
import requests

resp = requests.get(
    "{{ public_api_url }}/research/readings",
    params={"method": "takakura", "limit": 1000},
    timeout=30,
)
resp.raise_for_status()

df = pd.DataFrame(resp.json()["items"])
df["recorded_at"] = pd.to_datetime(df["recorded_at"])
print(df[["recorded_at", "temperature_c", "stage_name"]].head())
4

Page through everything

When there are more rows, the response carries a next_cursor. Send it back as cursor until it comes back null.

Python
url = "{{ public_api_url }}/research/readings"
params = {"limit": 5000}
rows = []

while True:
    page = requests.get(url, params=params, timeout=30).json()
    rows += page["items"]
    if not page["next_cursor"]:
        break
    params["cursor"] = page["next_cursor"]
